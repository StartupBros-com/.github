# StartupBros-com/.github

Default community health files for StartupBros-com repositories. GitHub shows each file here in every repository in the organization that doesn't have its own:

- [`CONTRIBUTING.md`](CONTRIBUTING.md): how to contribute. Issues and pull requests are open to everyone, including AI-assisted contributions.
- [`SECURITY.md`](SECURITY.md): how to report a vulnerability privately.

A repository's own file always takes precedence. A change merged here applies at once to every repository without its own file, so keep these files generic: no repository-specific commands and no private details.
