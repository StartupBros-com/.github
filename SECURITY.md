# Security policy

This is the default policy for StartupBros-com repositories that don't have their own `SECURITY.md`.

## Reporting a vulnerability

Report it privately through GitHub: open the repository's **Security** tab and choose **Report a vulnerability**. Don't put vulnerability details in a public issue, pull request or discussion.

If that option isn't available to you, open an issue titled `security` with no details in the body, and a maintainer will contact you privately.

Include the affected repository and the version or commit, what an attacker could do, and the smallest reproduction you have. Never include real secrets, tokens or personal data in a report.

## Supported versions

Unless a repository says otherwise, security fixes land on the default branch and in the next release.

## Scope

In scope: code, GitHub Actions workflows and published packages from StartupBros-com repositories.

Out of scope: vulnerabilities in third-party dependencies or services (report those upstream), social engineering, and volumetric denial of service.
